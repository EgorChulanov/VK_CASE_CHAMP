# Состояние решения

Подготовлена [[../presentation/Digital Cat$_strategy_msk.pdf|презентация]] команды Digital Cat$ для московского отбора. На обложке указаны четыре участника. Страницы 1–8 содержат предложение, страницы 9–22 раскрывают методику, ограничения, аналоги, пилот и сценарную экономику.

Результат основан на семи листах синтетического датасета организаторов. Коммерческие параметры заданы командой. Для определения реального эффекта нужен эксперимент в VK. Сведения о подаче заявки отсутствуют.
