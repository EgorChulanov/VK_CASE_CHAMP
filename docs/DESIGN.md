# Интерфейс и иллюстрации

В прототипе «Пульт продаж» продавец работает с карточкой, публикацией и заказом. Покупатель открывает товар в ленте и видит способ получения до оформления. Существующие объекты магазина сверены с [материалами VK Education](https://object2-ac.vk-apps.com/vk-education-0554ff56-27eb-4093-a702-685722cef6d9/media/94/d9943f73e80741b3b0b18a183d925bbd.pdf) и кадром консультации на 10:00. Сам Пульт продаж представляет предлагаемое расширение.

Для слайда 5 использованы снимки локального прототипа на настольном и мобильном экранах. Рамка MacBook Pro 14 взята из [экспортов Apple Design Resources](https://github.com/jamesjingyi/mockup-device-frames). Рамка iPhone 16 Pro из [weirdapps/mockups](https://github.com/weirdapps/mockups). [Фотография керамической кружки](https://images.unsplash.com/photo-1514228742587-6b1558fcca3d). Шрифт Montserrat распространяется по SIL Open Font License, текст лицензии включён в presentation/fonts.

Титул использует название со страницы 1 исходного задания. Пять скриншотов «финал ура» послужили примером для структуры резюме, карты процесса и ссылок по QR. Из Т-Банка и Альфы взят принцип показывать рабочий интерфейс на устройстве. По примеру Veya отделены наблюдения на данных от целевых эффектов продукта.
