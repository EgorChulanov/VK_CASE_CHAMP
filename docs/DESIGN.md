# Оформление и экраны

Обложка использует знаки VK Education и ВКонтакте из задания. Внутри презентации и в README используется знак ВКонтакте из официального пакета иконок VKUI. У команды отдельный авторский [векторный знак](../presentation/assets/digital-cat.svg).

Крупная надпись на обложке набрана VK Sans Display Expanded Bold из фирменного комплекта. Основной текст, заголовки разделов и числа набраны фирменной гарнитурой VK Sans Text в начертаниях Regular, Medium и DemiBold. Начертания скачаны с официального сайта VK Sans и встроены в PDF. [Гарнитуры VK](https://vksans.ru/).

На с. 7 снимки работающего кабинета и покупки в двух браузерных сеансах. Рамки MacBook и iPhone наложены по прозрачной области дисплея, отдельно проверены края экрана и вырез камеры. Скриншоты и рамки сведены в изображения до экспорта PDF. [Рамки MacBook](https://github.com/jamesjingyi/mockup-device-frames) и [рамки iPhone](https://github.com/weirdapps/mockups).

На слайде команды два настоящих портрета из командной страницы Cup Moscow. Для Максима и Анфисы использованы монограммы. Два файла HEIC из переписки содержат примеры оформления презентаций.

Схема на с. 11 разделяет действия продавца, покупателя и магазина. Она показывает проверку условий, развилку выдачи и отмены. Полная карта пути содержит задачи, точки контакта, возможные барьеры, действия продукта и наблюдаемые показатели.

Страница жюри и автономная карта используют VK Sans Text. Подписи на графиках и в схеме заказа набраны той же гарнитурой. Надписи на значках README переведены в векторные контуры VK Sans Text. Основной текст Markdown отображает сам GitHub.
