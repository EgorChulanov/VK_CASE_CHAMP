# Открытые решения

Проверены деревья восьми указанных репозиториев. В [снимке](../analysis/public_repositories.json) сохранены ветки, версии и имена файлов.

Наиболее близкий готовый пример по содержанию: [AVAS, стратегия социальной коммерции](https://github.com/Volkov-Andrey/VK_Case_Champ/blob/HEAD/AVAS_strategy.pdf), с. 3. Команда связывает рост GMV с несколькими инициативами, включая наполнение каталога контентными товарами. Их оценка роста относится к собственной модели. Для нашего кейса основной вопрос иной: сколько дополнительных бизнесов начинают получать заказы. Поэтому единица эксперимента у нас бизнес, а основной показатель учитывает долю продавцов с заказами.

У [404](https://github.com/Isnob/404_vk_case_champ_2026/tree/develop) обнаружены материалы текущего задания и выгрузки данных. На проверенной ветке готовая стратегия не подтверждена. У Eldrich1Herz и Eeelizaveta-code есть аналитика контентного потенциала и связок автора с товаром. Её можно применять на этапе выбора контента после проверки готовности магазина. igor688-hub разбирает подписки в VK Видео, iliarodiushkin и very-cool-dude работают с HTML5-играми. У UnemployedTocha обнаружен Android-проект. Принадлежность авторов этих решений к текущему составу соперников не установлена.

В ветке [продуктового разбора 404](https://github.com/Isnob/404_vk_case_champ_2026/tree/Alexandr-Zeifert/docs/product-tech) есть аудит пути продавца. Вопрос получения товара стоит проверить в пилоте. Оценку причинного эффекта по чужому аудиту не делаем.
