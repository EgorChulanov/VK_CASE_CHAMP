# Магазин сообщества

Продавец ведёт каталог, выпускает записи, отвечает покупателям и закрывает заказы. Покупатель находит товар в ленте, на витрине или в Маркете. В учебном магазине один аккаунт продавца и один аккаунт покупателя.

## Запуск

Нужны Python 3.10+ и Node.js 22.12+. Из корня проекта выполните команду.

```bash
./demo/run.sh
```

Откройте [магазин](http://127.0.0.1:8765) в обычном и приватном окнах. В первом войдите продавцом, во втором покупателем. Для другого порта задайте PORT. Для отдельной базы задайте SHOP_DB. Начальная мастерская содержит два опубликованных товара, один черновик и три примера заказов.

## Проверить покупку

1. В обзоре магазина откройте черновик «Кружка Мел». Добавьте адрес самовывоза и текст записи, затем опубликуйте товар. Свой товар можно добавить из каталога, приложив JPG, PNG или WebP до 2 МБ.
2. В «Публикациях» нажмите «Новая запись», выберите товар и выпустите второй пост. У записи появится собственная статистика.
3. В окне покупателя откройте именно эту запись в ленте. Сохраните товар, выберите получение, добавьте его в корзину и оформите. Для курьера потребуется адрес.
4. В заказе задайте вопрос мастерской. У продавца он появится в «Сообщениях» и в обзоре. Откройте его, ответьте и подтвердите выдачу. В карточке покупателя обновятся переписка и статус.
5. В публикациях откройте результат поста. В «Аналитике» выберите нужную точку входа и посмотрите конкретные заказы. При переходе через Маркет заказ учитывается в Маркете.
6. Проверьте другой исход продажи. Оформите ещё один товар и отмените заказ с причиной. Остаток восстановится один раз.

## Что хранится

React и VKUI отображают интерфейс. FastAPI проверяет действия по роли. SQLite хранит товары, изображения, публикации, открытия, заказы, сообщения и смены статусов. Количество и цена фиксируются в момент покупки. Повтор одного запроса не создаёт вторую покупку, публикацию или сообщение. Параллельные покупки проверяют остаток в транзакции.

Точка входа соответствует последнему открытию карточки перед добавлением в корзину. Ранее созданные заказы без источника остаются в группе «Источник неизвестен». Данные двух ролей сохраняются между запусками. Реальные VK ID, платежи и службы доставки потребуют отдельных подключений. Сервер предназначен для показа на локальном компьютере.

## Проверки

После первого запуска перейдите в папку demo. Первая команда проверяет API и сохранность данных. Браузерная проверка запускает отдельный магазин во временной базе и проходит путь в двух независимых сеансах.

```bash
.venv/bin/python -m unittest discover -s tests -v
npx playwright install chromium
npm run test:journey
```

Для своего браузера можно указать CHROMIUM_PATH, для другого окружения Python переменную SHOP_PYTHON. Набор снимков из контрольного пути сохраняется в каталог, указанный в SHOP_SCREENSHOTS.
