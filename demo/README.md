# Магазин сообщества

Прототип для VK Case Champ. Продавец и покупатель работают с одним магазином в двух независимых окнах. Реальные платежи и отправка посылок находятся за пределами прототипа.

## Запуск

Нужны Python 3.10+ с venv и Node.js 22.12+ с npm. Из корня репозитория:

```bash
./demo/run.sh
```

Откройте http://127.0.0.1:8765 в обычном и приватном окне. В первом выберите продавца, во втором покупателя. Для другого порта задайте переменную PORT.

1. В кабинете продавца нажмите «Подготовить товар». Укажите текст записи и адрес самовывоза или срок доставки. Опубликуйте товар.
2. У покупателя откройте товар в ленте. Кнопка «Сохранить» добавляет его в раздел «Маркет». Положите товар в корзину, проверьте стоимость получения и оформите заказ. Для курьера нужен адрес.
3. В кабинете продавца откройте заказ по его номеру. Подтвердите выдачу либо укажите причину отмены. Тот же статус появится у покупателя. При отмене остаток восстановится.
4. В аналитике выберите показатель, чтобы увидеть заказы, из которых он складывается.

## Данные и ограничения

React и VKUI отвечают за интерфейс, FastAPI и SQLite за запись заказов. У прототипа один учебный покупатель и один продавец. Все входы одной роли открывают одну и ту же учётную запись. Данные сохраняются в локальном файле shop.sqlite3. Для независимого прогона задайте SHOP_DB с путём к отдельному файлу. Сервер запускается на локальном адресе.

Цена и условия сохраняются в заказе. Повтор запроса сохраняет номер заказа. Параллельные покупки проверяют остаток в одной транзакции. Изменившаяся версия карточки требует повторного открытия в редакторе.

Для проверок активируйте окружение, созданное при запуске, перейдите в demo и выполните:

```bash
python -m unittest discover -s tests -v
```
